# 韩国队列最终验证集 v2 — 修订说明（2026-09-12）

## 修订内容（纯簿记修正，不改变任何冻结结果）
v1 文件中男性（sex=1）的派生标签列存在填充错误：
- v1 男性的 `op_primary` 被误填为亚洲参照标签（255 事件，8.1%），`endpoint_ref` 误标为 `KNHANES_Asian_male_native`，且男性 NHANES 参照 T 值列（`fn_t_nhanes`/`ls_t_nhanes`/`t_min_nhanes`/`op_nhanes`）为空。
- 冻结的 M4 全性别扩展分析实际使用的男性主标签为统一年轻白人女性参照（436 事件，13.8%）——该标签在分析会话内联计算，未读取 v1 的男性派生列，故 v1 的列错误未影响任何已报告结果。
- v2 已为男性补齐 NHANES 参照 T 值列并重置 `op_primary`/`endpoint_ref`，男性 `op_primary`（436 事件）与冻结结果 JSON（韩国全性别扩展_M4结果_v1.json）逐位一致。
- 亚洲参照列（`*_asia`）作为敏感性标签原样保留。

## 参照约定（与正文 Methods 一致）
- 主标签（两性）：统一年轻白人女性参照，分部位——股骨颈 NHANES III（均值 0.858，SD 0.120）；腰椎 L1–L4 美国年轻成年女性参照（均值 1.047，SD 0.11）。
- 已知第三小数位差异：文件内女性标签计算时腰椎 SD 取 0.111，M4 会话男性标签取 0.110（均为已发表参照 0.11 的舍入）；差异至多影响男性 13/3,154 例边界分类，冻结结果按各自会话计算，未重跑。
- 敏感性标签：性别匹配亚洲参照（女性股骨颈 0.803/0.107；男性股骨颈 0.846/0.124 等）。

## 验证记录
- 女性 `op_nhanes`：用声明常数从 BMD 反推，与文件标签 100% 一致（1,868 事件）。
- 男性 `op_nhanes`（v2 新增）：与冻结 M4 JSON 的 436 事件（13.8%）精确一致。
- 女性所有列在 v1→v2 间零改动（逐列断言通过）。
